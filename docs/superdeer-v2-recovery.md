# 超鹿启动转圈兼容恢复

用户报告 v1 导致 App 持续转圈。旧模块对 getSplashData/V2 清空 data.splashes，没有其他拦截。空数组与启动逻辑不兼容、MITM 兼容性均为待确认原因；没有故障 HAR 或真机对比，不能断言根因。

2026-10-25 搜索社区中的超鹿运动、chaolu.com.cn、getSplashData 未找到可核实的专用成熟方案。v2 暂停此模块全部改写与 MITM，恢复服务端原响应；开屏广告会暂时恢复。若其它模块也解密此域名，停用本模块不会移除其它模块的解密设置。

这是兼容恢复措施，不是已完成的去广告修复；更新后需强退冷启动确认是否恢复。后续故障抓包应包含启用旧模块时的启动全过程，并对照停用模块后的正常启动，以验证客户端接受的广告空状态。
