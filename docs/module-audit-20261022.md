# 半年模块审查

范围：Git 历史自 2026-04-22 起变更且仍存在的 37 个 `.sgmodule`，另含 `Module/ad.conf` 规则参考文件。已删除模块不作为缺失依赖。

确认并修复：

- 兴业生活 `/ad` 前缀会匹配 `/address`、`/addCard`、`/advice`，原 `.*` 还可跨入查询字符串。v2 收紧主机和独立路径段，添加正常业务及伪主机回归。这是正则可复现误匹配，未声称真实请求曾被拦。
- 移动云盘 JSC 脚本依赖 `atob`，旧测试注入该函数掩盖缺失。v6 自带 Base64 解码，测试不提供 `atob` 或 `Buffer`，覆盖 Basic 票据与手机号。

检查：37 个模块均以补齐 FINAL 的临时配置通过本机 Surge 原生解析；模块脚本名称无重复，本仓引用未发现缺失。3 个外部脚本 URL 可下载并解析为 JS。合成测试不能替代实际 App 使用；本轮无新 HAR、无 iPhone UI 或真实凭据上报验证。

保留待实测项：高德地点详情白名单仍可能过滤新增业务模块；移动云盘异步上报与脚本结束的实际寿命需用设备和接收器回读验证。没有证据时未扩大业务清理规则。
